# Vidyut — AI-Native Grid Intelligence Platform

Vidyut is an enterprise-grade, AI-native grid intelligence platform engineered to accelerate India's renewable energy transition. Built for power utilities, grid operators (SLDCs/RLDCs), and energy distribution companies (DISCOMs), Vidyut provides the telemetry and predictive intelligence needed to modernize grid infrastructure.

Live Animated Grid Preview (Inspired by India's national electrical transmission network):
* Abstract transmission towers, substations, load centers, and renewable energy generators.
* Dynamic energy routing and self-balancing grid pulse simulation.

---

## Key Features

1. **Renewable Curtailment Forecasting**: Physics-informed machine learning models that map solar and wind over-generation risks across regional dispatch centers (SLDCs) 4 to 72 hours in advance.
2. **Transmission Bottleneck Localization**: High-resolution identification of feeder lines, transformer thermal limits, and node congestion points prone to grid trips.
3. **Utility Decision Support**: Real-time dispatch advisory designed to help DISCOMs and state power utilities minimize Aggregate Technical & Commercial (AT&C) losses.

## Tech Stack

* **Frontend**: React (Functional Components + Hooks)

* **Visuals**: High-performance HTML5 Canvas with custom animation engine and event-driven interactivity (parallax & touch pulses)

## Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/codemaddy17/vidyut.git
   cd vidyut
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
